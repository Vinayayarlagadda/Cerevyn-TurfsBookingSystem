#Cerevyn Turf Booking System

A Modern Turf Booking System built for managing sports turfs online. Users can browse turfs, view details, and book directly. Admins can add new turfs.
Technologies: Spring Boot, Java, MySQL, HMTL/CSS/JS

Features:
-> User registration & login
-> View all turfs and thier details(location,price,sport type)
-> Book turf
-> User-friendly interface with images
